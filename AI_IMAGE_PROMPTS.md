# AI Image Generation Prompts

These prompts are designed for AI image generators like DALL-E 3, Midjourney, Stable Diffusion, or similar tools. Generate these images and save them to the `/images/` folder with the exact filenames specified.

---

## Image Requirements

- **Format:** JPG (for photos/illustrations), PNG (for diagrams with transparency)
- **Dimensions:** 1920x1080px (landscape) or 1080x1920px (portrait as specified)
- **Style:** Modern, professional, abstract, tech-focused
- **Color Palette:** Blues, greens, purples - professional and educational
- **Mood:** Optimistic, innovative, trustworthy

## Quality Tips

1. **Consistency:** Use the same AI service for all images to maintain visual coherence
2. **Resolution:** Generate at 1920x1080 or higher, then resize if needed
3. **Iterations:** Generate 3-4 variations per prompt, select the best
4. **Color Matching:** Stick to blue/green/purple palette for consistency with website
5. **Compression:** Use TinyPNG (https://tinypng.com) to reduce file sizes after generation
