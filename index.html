Centralized Student Dashboard

Unifying Student Data for Smarter Decisions

Break down data silos. Empower proactive advising. Improve student retention through data-driven insights.

Executive Summary

Transforming student retention through unified data and predictive analytics

The Challenge & Our Solution

Horizon State University (HSU) experienced below-average student retention due to decentralized data systems that caused advising to be reactive and increased the administrative burden. Critical information about students—academic, financial, housing, and engagement details—existed in silos within departmental knowledge portals.

This project presents the Centralized Student Dashboard, a functional prototype web application developed on a modern React, FastAPI, and MongoDB technology stack. This solution brings all the disparate student data in the system together for 1,000 students into one actionable platform.

The primary feature was a multi-factor predictive risk assessment model (weighted 40% GPA, 30% Attendance, 20% Engagement, and 10% Financial status) that calculated and produced an individualized risk score immediately. The application shifted the advising model from retroactive remediation to proactive support.

Key Outcomes

✓ Identified 291 at-risk students (29.1%) enabling proactive intervention

✓ Achieved 40% faster data retrieval compared to manual cross-system queries

✓ Established 70.9% retention rate baseline with clear path to 85% target

✓ Unified academic, financial, housing, and engagement data into Student 360° Profiles

✓ Enabled evidence-based decision making through Pulse Tracker and Department Performance analytics
